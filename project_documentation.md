# InternAI: The Ultimate AI-Powered Internship Engine & Career Command Center

## 1. Executive Summary
**InternAI** is a state-of-the-art, high-fidelity career platform designed to revolutionize the internship discovery and recruitment lifecycle. Unlike traditional portals, InternAI leverages **NVIDIA's high-performance LLMs (Llama 3.1)** and immersive UI/UX to provide a "Career Command Center" experience. It bridges the gap between talent and opportunity through automated skill synthesis, real-time proctored assessments, and voice-driven AI coaching.

## 5. System Architecture
The platform utilizes a **Modern Decoupled Monorepo Architecture**:

- **Frontend:** React (Vite) with **Framer Motion** for premium glassmorphism animations.
- **Backend:** High-performance Node.js/Express server with **Drizzle ORM**.
- **AI Layer:** Integration with **NVIDIA NIM** (Llama-3.1-8b-instruct) for low-latency intelligence.
- **Security:** Secure Google OAuth 2.0 and session-based authentication.
- **Communication:** Real-time feedback loops via Web Speech API and facial expression sensors.
